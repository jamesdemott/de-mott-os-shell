AWAY FROM THE DESK

Setup

When this page is open on your phone your Mac is almost certainly asleep, so there is nothing on localhost to ask. It reads the copy of data/ that the Mac has been committing all along — your private repo — and caches it here so it still draws with no network at all. It needs a token to do that, because the repo is private.

The token

A fine-grained token, scoped to this one repository, revocable from GitHub in one click. It is stored only on this device and is never sent anywhere but api.github.com.

  1. Open github.com → fine-grained tokens.
  2. Under Repository access pick Only select repositories, and choose de-mott-os.
  3. Under Repository permissions set Contents to Read and write. Write is what lets this phone capture and tick: it adds a file to data/outbox/, which your Mac replays. It never edits your data directly.
  4. Generate it, copy it, and paste it here. Nothing echoes it back.
